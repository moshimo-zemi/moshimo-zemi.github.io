プライバシーポリシー

制定日：2026年11月8日

このポリシーは、もしもゼミの運営者（以下「運営者」）が使うツール「もしもゼミ 予約投稿」（以下「本ツール」）が、Googleアカウントのデータをどう扱うかを定めます。

1. 本ツールの目的

本ツールは、運営者が自分のYouTubeチャンネル「もしもゼミ【思考実験】」に動画をアップロードし、公開日時を予約するための、運営者専用のツールです。運営者以外の方に提供していません。

2. 使うデータ

本ツールは、Googleのログインと許可（OAuth）を通して、YouTube Data API と YouTube Analytics API を次の範囲で使います。

  • youtube.upload：運営者のチャンネルに動画をアップロードする
  • youtube：運営者のチャンネルの動画の公開設定・再生リストを管理する
  • yt-analytics.readonly：運営者のチャンネルの再生数などの数字を読む

運営者のチャンネル以外のデータは扱いません。

3. 保存のしかた

許可のためのトークンは、運営者のパソコンの中だけに、本人しか読めない設定で保存します。外部のサーバーには保存しません。

4. 第三者への提供

取得したデータを第三者に販売・提供・共有することはありません。広告のためにも使いません。

5. Googleのポリシーへの準拠

本ツールがGoogle APIから受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。YouTubeのデータは YouTube 利用規約 と Google プライバシーポリシー の下で扱われます。

6. 許可の取り消し

本ツールへの許可は、Googleアカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。取り消すと、本ツールは保存していたトークンを使えなくなります。

Privacy Policy (English)

Effective: November 8, 2026

"もしもゼミ 予約投稿" (the "Tool") is a private tool used only by the operator of the YouTube channel "もしもゼミ【思考実験】" to upload videos to the operator's own channel and schedule their publication. It is not offered to anyone else.

  • Data used: via Google OAuth, the Tool uses the YouTube Data API and YouTube Analytics API with the scopes youtube.upload, youtube, and yt-analytics.readonly, only for the operator's own channel (uploading videos, setting privacy/schedule and playlists, reading channel statistics).
  • Storage: OAuth tokens are stored only on the operator's own computer with owner-only file permissions. No data is stored on external servers.
  • Sharing: No data is sold, shared, or transferred to third parties, and none is used for advertising.
  • Compliance: The Tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. See also the YouTube Terms of Service and the Google Privacy Policy.
  • Revoking access: Access can be revoked at any time at Google Account permissions.
